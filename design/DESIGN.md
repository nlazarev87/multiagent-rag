# Дизайн: анализ и план улучшения

> Документ фиксирует анализ текущего UI, целевую дизайн-систему и роадмап.
> Мокапы лежат в `design/mockups/` и открываются браузером или как PNG.

## Текущее состояние

Весь интерфейс — один файл `src/web/index.html` (~1970 строк), без сборки.
Светлая схема, шрифт Segoe UI, три колонки: диалоги, агент/документы, превью.
Внизу полоса логина/роли. Управление — полноэкранная накладка `#admin`.

## Что слабо сейчас

1. **Нет дизайн-системы.** CSS-переменные есть, но не систематизированы: нет
   шкалы отступов, шкалы типографики, единых радиусов/теней. Разные паддинги
   8/12/14 px соседствуют хаотично.
2. **Панель управления — сырая.** Это самый слабый экран: плоские текстовые
   кнопки сверху и DOM, который набивается на лету. Нет таблиц, бейджей
   состояния, структуры. Выглядит как отладочный вывод, а не консоль.
3. **Нет визуальной иерархии.** Весь текст 13px одного веса. Заголовки,
   вторичный текст и подписи почти не различаются.
4. **Иконки — текстовые глифы** (`⌕ ↑ → × ▸ ▾`). Нет единого набора, выглядят
   разнородно и плохо масштабируются.
5. **Чат примитивный.** Вопрос — серый прямоугольник, ответ — сплошной текст.
   Нет аватаров, нет оформления источников, оценки занимают много места.
6. **Превью документа плоское.** Фрагменты как абзацы, подсветка найденного —
   просто фон. Нет заголовка документа, нет «страницы».
7. **Нет пустых состояний.** «Откройте документ» / «Нет документов» — тусклый
   текст без иконки и действия.
8. **Нет микровзаимодействий.** Ховеры есть, но без переходов; нет focus-видимых
   состояний; нет анимаций раскрытия.
9. **Нет тёмной темы.** Cursor ассоциируется с тёмной схемой; её отсутствие
   заметно.
10. **Вход — голый.** Простая карточка без брендинга и иерархии.

## Целевая дизайн-система

Токены в `design/mockups/style.css`.

- **Цвет.** Нейтральная шкала (bg/panel/paper/sink) + акцент `#4F46E5`,
  семантические `--ready/--danger/--warn`, подсветка найденного `--hit`.
  Полная тёмная тема через `[data-theme="dark"]`.
- **Типографика.** Segoe UI Variable (+ fallback), Cascadia Code для моно.
  Шкала 11/12/12.5/13/13.5/15/19 px.
- **Радиусы.** 4/6/8/12 px.
- **Тени.** 3 уровня.
- **Компоненты.** btn (primary/ghost/soft/danger/icon/round), input/select,
  chip, badge (ok/off/warn/mute), toggle, check, card, table, tree, tabs,
  composer, empty state, kbd, access-аккордеон, audit-строка.

## Роадмап

Реализация идёт треком **Wave 7** (`wave-7-ui`). Задачи уже в GitHub:
issues [#185–#196](https://github.com/nlazarev87/multiagent-rag/issues?q=label%3Awave-7-ui),
ветки `wave7/<slug>`. Концептуальная последовательность:

1. **Токены и базовые компоненты** — перенос CSS в систему токенов.
2. **Каркас окна** — 3 колонки, sashes, строка состояния.
3. **Сайдбар диалогов** — кнопка «Новый диалог», список, user-chip.
4. **Чат агента** — пузыри, аватары, чипы источников, оценки, композер.
5. **Дерево документов** — иконки, поиск, загрузка.
6. **Превью документа** — вкладки, заголовок, подсветка найденного.
7. **Панель управления** — левая навигация, таблицы, тумблеры, бейджи,
   матрица доступов, журнал.
8. **Вход / первый запуск.**
9. **Тёмная тема** + переключатель.
10. **Полировка** — переходы, focus-visible, доступность, пустые состояния.
