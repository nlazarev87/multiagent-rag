# Ответ

Код: `answer_agent` и соседние функции в [src/agents.py](../src/agents.py). Модель вызывает [src/llm.py](../src/llm.py).

Собирает текст ответа по уже найденным кускам. Проверка ещё впереди. Здесь ответ можно вернуть без модели, если нужная строка уже лежит в кусках.

## Вход и выход

`answer_agent(query, clear_query, chunks, work_turns, feedback=None)`. Если кусков нет, ответ — «В документах нет ответа.» Иначе порядок такой:

1. Латинское слово, которого нет в текущих кусках, ищется в остальных кусках уже выбранных документов и ставится первым.
2. Для «что такое» вперёд ставится раздел со словами «наименован» или «характеристик», где есть сам термин. Кусок протокола, где термин только в роли отправителя или получателя, убирается.
3. Без отзыва проверки вопрос со списком или числом может закрыться строкой обзора таблицы, без вызова модели.
4. Иначе модель получает текст и примеры из `data/prompts/`. Повторная ссылка на тот же номер в хвосте снимается.

## Что нельзя сломать

- Для вопроса «сколько» строка «Разных значений в столбце «X»: N. Список: …» отвечает фразой «N {подпись столбца} [n]». Другой заголовок, который совпал сильнее, не отменяет эту строку.
- Латинское слово не открывает новый документ. Оно читается только из файлов, которые поиск уже выбрал.
- Обзор не подменяет ответ, если это повтор после отзыва проверки. Иначе проверка не может заставить модель переписать текст.
- Ответ, который обрывается на «:», «следующие» или «следующее», здесь не чинится. Его отклоняет проверка, см. [check.md](check.md).

## Настройки

`data/prompts/answer.json` — текст для модели, лимит `prompt_tokens`, фразы отзыва. `data/prompts/fewshot.json` — примеры. Примеры не удалять: проверка отдельно ловит длинные слова, взятые из них.
