# Диалоги и папки

Код: [src/workspace.py](../src/workspace.py) и [src/dialog.py](../src/dialog.py).

`dialog.py` — память процесса, последние 20 ходов на диалог. Её читает сборка вопроса. `workspace.py` хранит диалоги. Папки базы — в `tree.json` рядом с её папкой файлов (`src/trees.py`). Пока тест подменяет только `workspace.PATH`, дерево остаётся в этом файле. Файлы в git не входят.

## Вход и выход

`prepare_dialog` поднимает сохранённые ходы в память и не создаёт новый диалог. `append_turn(..., create=False)` не возрождает диалог, который человек успел удалить, пока шёл ответ.

`snapshot(known, keep)` показывает дерево. `known` — имена в индексе. `keep` — имена, которые ещё лежат в inbox. `put_tree` проверяет присланное дерево теми же правилами.

Оценки — пять полей от 1 до 5. Пустое и отсутствующее поле не затирает уже стоящую оценку. Число вне диапазона не записывается.

## Что нельзя сломать

- Запись файла под замком. Оценка и сохранение дерева не должны затирать ход, который параллельный ответ как раз дописывает. Временный файл у каждой записи свой.
- Битый JSON читается как пустое рабочее место и не заменяется, пока следующая успешная запись сама не перепишет файл.
- В дереве только имена известных файлов, без папок в самом имени. Повтор папки, цикл и путь с каталогом выкидываются.
- Пока индекс прячет документ, `keep` удерживает его в папке. Без этого обновление страницы вытаскивает файл в корень.
- Удаление файла убирает его из дерева и не удаляет диалоги, где этот файл цитировался.
- Заголовок диалога ставится по первому вопросу и дальше не переписывается каждым новым ходом.
