# HTTP API

Код: [src/api.py](../src/api.py). Страница: [src/web/index.html](../src/web/index.html).

FastAPI на `127.0.0.1:8000`. При старте в фоне переиндексирует `data/inbox` и грузит модель. Пока это идёт, `/ready` не 200.

## Маршруты

- `GET /` — страница.
- `GET /ready` — готовность и оценка оставшихся секунд по прошлому `data/load_time.txt`.
- `GET /documents`, `GET /documents/{name}` — список и текст одного файла. Чужое имя и путь наружу inbox не отдаются.
- `DELETE /documents/{name}` — удаляет файл из inbox и из индекса, убирает его из дерева, диалоги сохраняет.
- `POST /documents` — переиндексировать каталог. Только `data/inbox`.
- `POST /upload` — записать файлы и обновить индекс.
- `GET /ui`, `PUT /ui` — снимок диалогов и дерева.
- `POST /ui/dialogs`, `GET` и `DELETE /ui/dialogs/{id}` — диалоги.
- `PATCH /ui/dialogs/{id}/turns/{index}/ratings` — оценки 1–5.
- `POST /query` — вопрос. Перед моделью ход восстанавливается из `workspace.json`, после ответа дописывается на диск.

## Инварианты

- Пока индекс не готов, `GET /ui` возвращает `workspace.load()` и не вызывает `list_documents`. Иначе старт блокируется на Chroma, и сохранённые диалоги не появляются.
- Загрузка сначала пишет байты, потом читает текст. Непрочитанный файл, пустой файл или сбой на следующем файле пакета откатывают уже записанные байты. Прежний файл при неудачной замене остаётся.
- Два запроса загрузки не пересекаются: между записью и откатом стоит замок.
- Имя загрузки — только база имени. Симлинк и выход из `data/inbox` отклоняются.
- Дерево после загрузки и удаления строится с `keep`: файл, который ещё на диске, но уже исчез из индекса на время переиндексации, остаётся в своей папке.
