# Страница и запросы

Код: [src/api.py](../src/api.py). Страница: [src/web/index.html](../src/web/index.html).

Без сессии список файлов, вопрос и управление отвечают 401. Сервер на `127.0.0.1:8000`. При старте в фоне заново читает папки баз и грузит модель. Пока это идёт, `/ready` не отвечает 200. `/ready` не перечисляет базы.

## Маршруты

- `GET /` — страница.
- `GET /ready` — готовность и оценка оставшихся секунд по прошлому `data/load_time.txt`.
- `GET /documents` — список файлов, которые этому человеку можно смотреть: объекты с `kb_id`, `kb_name`, `name`.
- `GET /documents/{name}` и `DELETE /documents/{name}` — старый адрес без базы, ответ 404.
- `POST /documents` — заново прочитать папку базы «Документы» из реестра. Другой путь с клиента — 400.
- `POST /upload` — записать файлы в выбранную базу. Без id базы — 400, молчаливой записи в `data/inbox` нет. `GET /upload-targets` отдаёт базы, куда можно загружать, и признак, можно ли создать новую.
- `GET /ui`, `PUT /ui` — диалоги и дерево.
- `POST /ui/dialogs`, `GET` и `DELETE /ui/dialogs/{id}` — диалоги.
- `PATCH /ui/dialogs/{id}/turns/{index}/ratings` — оценки от 1 до 5.
- `POST /query` — вопрос. Перед моделью ход поднимается из файла диалогов этого человека, после ответа дописывается. Базу для вопроса человек не выбирает.
- `GET /auth/state` — только признак, есть ли уже люди. Нужен форме до входа.
- `POST /setup`, `POST /login`, `POST /logout`, `GET /me` — вход. Свой пароль меняется через `POST /me/password` вместе со старым. Чужой пароль задаёт тот, у кого есть «управлять людьми», и старая сессия этого человека гаснет.
- `GET /kb/{id}/documents/{name}/preview` и `DELETE` — файл конкретной базы. Старый адрес без базы отвечает 404. Чужой каталог индекса без допуска не читается.
- `GET/POST /admin/users`, `PATCH/DELETE /admin/users/{id}` — люди. Последнего управляющего нельзя удалить, заблокировать или лишить четырёх общих действий: ответ «Нельзя оставить систему без управляющего».
- `GET/POST /admin/roles`, `PATCH/DELETE /admin/roles/{id}` — роли, шесть общих действий и четыре действия на базу. Действие роли само базу не открывает.
- `GET/POST /admin/groups`, `PUT /admin/groups/{id}/members`, `DELETE` — группы из людей и ролей. Роль в группе — все, у кого она есть сейчас и будет потом.
- `GET /admin/kb`, `POST/DELETE /admin/kb/{id}/allow` и `/deny`, `POST /admin/kb/{id}/self`, `PUT .../people/{id}/actions` — кому база открыта и закрыта. «Открыть себе» включает вход по имени и четыре личных действия и не меняет строку роли. Если роль или группа закрывает базу, текст «Роль или группа закрывает эту базу».
- `POST /kb` — создать базу. Создатель открыт по имени, роль не открывается.
- `GET /admin/audit` и `GET /admin/audit/{id}` — журнал, не больше 50 строк. Период включает указанные секунды. Продолжение — время последней строки в `before` и её id в `before_id`, иначе строки той же секунды пропадают. Без «смотреть журнал» — 403. Один просмотр пишет одно событие `audit_view`.

## Что нельзя сломать

- Пока индекс не готов, `GET /ui` возвращает диалоги этого человека и уже записанные папки и не вызывает `list_documents`. Иначе старт ждёт индекс, и старые диалоги не появляются.
- Загрузка сначала пишет байты, потом читает текст. Непрочитанный файл, пустой файл или сбой на следующем файле пакета возвращают уже записанные байты. Прежний файл при неудачной замене остаётся.
- Два запроса загрузки не пересекаются: между записью и откатом стоит замок.
- Имя загрузки — только само имя файла. Ссылка на другой файл и выход из папки выбранной базы отклоняются.
- Вопрос без права «спрашивать» ни в одной базе не вызывает модель и отвечает «В документах нет ответа.»
- Команда `python -m cli` без `--user` отказывает. Пароль берётся из `CLI_PASSWORD` и не печатается и не пишется в журнал.
- После загрузки и удаления файл, который ещё на диске, но уже исчез из индекса на время перечитывания, остаётся в своей папке.

## Проверка

`tests/test_api.py`. Отдельной проверки качества ответа у этих маршрутов нет. Если по пути изменился сам ответ, измеряется он. Контракт страницы закрывают эти тесты.
