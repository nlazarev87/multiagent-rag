# Загрузка документов

Код: [src/ingest.py](../src/ingest.py).

Превращает файлы inbox в чанки. Поиск и ответ видят уже чанки, не исходный Word.

## Вход и выход

`ingest_dir` читает каталог и возвращает список чанков. У чанка есть `document_name`, `text`, `section`, `chunk_index`, `checksum` и текст для эмбеддинга. `chunks_from_blocks` делает то же из уже разобранных блоков: так загрузка проверяет один файл, не перечитывая весь inbox.

Берутся только `.txt`, `.md`, `.doc`, `.docx`. Старый `.doc` конвертирует LibreOffice. Файл, который не читается, пропускается. Остальные документы этого прохода остаются.

## Инварианты

- `VERSION` входит в checksum. Сейчас он равен 3: нумерованная строка вроде «1.2 Назначение» становится заголовком секции. Смена правил разбора без смены версии оставляет в индексе старый текст.
- Мягкий перенос «доку-» + «мента» склеивается в «документа». Дефис перед числом, после цифры и в «ISO-9001» остаётся. Иначе «6-10» превращается в «610».
- Видимый текст правки Word попадает в индекс. Удалённый прогон не попадает. Текст внутри content control не теряется.
- Ячейка таблицы хранит и абзацы, и вложенную таблицу. Пустая ячейка из-за пропущенной вложенной таблицы — ошибка разбора.
- Строка, которая начинается не с первой колонки, не сдвигает значения под чужие заголовки.
- Обзорная строка «Разных значений в столбце …» не обрезается по бюджету чанка: число в ней обещает полный список.
- Оглавление (стиль TOC) в индекс не идёт.

## Настройки

`config/runtime.json`: `tokens` (размер чанка), `overlap`, `intro` (сколько текста перед таблицей остаётся рядом с ней).

## Проверка

`tests/test_ingest.py`. Узел scorecard: `ingest` (`ingest_overview_complete`, `ingest_table_intro_group`, `ingest_version`).
