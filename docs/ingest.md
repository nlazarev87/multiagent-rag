# Загрузка документов

Код: [src/ingest.py](../src/ingest.py).

Читает файлы из inbox и режет их на куски текста для индекса. Поиск и ответ видят уже эти куски, не исходный Word.

## Вход и выход

`ingest_dir` читает папку и возвращает куски. У куска есть имя файла, текст, раздел, номер, контрольная сумма текста и текст для числовой модели поиска. `chunks_from_blocks` делает то же из уже разобранных блоков: так загрузка проверяет один файл и не перечитывает весь inbox.

Берутся только `.txt`, `.md`, `.doc`, `.docx`. Старый `.doc` конвертирует LibreOffice. Файл, который не читается, пропускается. Остальные документы этого прохода остаются.

## Что нельзя сломать

- Номер версии разбора входит в контрольную сумму. Сейчас он равен 3: строка вроде «1.2 Назначение» становится заголовком раздела. Если правила разбора сменились, а номер нет, в индексе остаётся старый текст.
- Перенос «доку-» + «мента» склеивается в «документа». Дефис перед числом, после цифры и в «ISO-9001» остаётся. Иначе «6-10» превращается в «610».
- В индекс попадает текст, который виден в Word. Удалённый фрагмент правки не попадает. Текст внутри поля формы не теряется.
- Ячейка таблицы хранит и абзацы, и таблицу внутри себя. Пустая ячейка из-за пропущенной внутренней таблицы — ошибка разбора.
- Строка, которая начинается не с первой колонки, не сдвигает значения под чужие заголовки.
- Строка «Разных значений в столбце …» не обрезается по длине куска: число в ней обещает полный список.
- Оглавление в индекс не идёт.

## Настройки

`config/runtime.json`: `tokens` — длина одного куска, `overlap` — сколько текста повторяется на стыке, `intro` — сколько текста перед таблицей остаётся рядом с ней.

## Проверка

`tests/test_ingest.py`. Имена проверок загрузки: `ingest_overview_complete`, `ingest_table_intro_group`, `ingest_version`.
