# Уточнение вопроса

Код: `clarify_agent` в [src/agents.py](../src/agents.py).

Делает строку, по которой реально ищут. Человеку по-прежнему показывается его исходный вопрос.

## Вход и выход

Если прошлый ход не выбран или вопрос самостоятельный, строка поиска равна вопросу. Иначе спереди добавляется прошлый вопрос. Если из прошлого ответа удалось снять опоры, они дописываются в конец.

Модель видит прошлый ход только когда строка поиска отличается от вопроса. Иначе в запрос не подмешивается чужой контекст.

## Что нельзя сломать

- Самостоятельный вопрос не переписывается. Лишние слова прошлого хода уводят поиск.
- Опоры берутся из прошлого ответа, не из выдуманного списка документов.
- Поиск вызывает `search_agent` уже с этой строкой, не с сырым вопросом человека.
