# Уточнение вопроса

Код: `clarify_agent` в [src/agents.py](../src/agents.py).

Делает строку, по которой реально ищут. Пользователю по-прежнему показывается его исходный вопрос.

## Вход и выход

Если история не выбрана или вопрос не зависимый, строка поиска равна вопросу. Иначе к вопросу спереди добавляется прошлый вопрос. Если из прошлого ответа удалось снять якоря, они дописываются в конец.

Ответ модели получает прошлый ход только когда строка поиска отличается от вопроса. Иначе в промпт не подмешивается чужой контекст.

## Инварианты

- Независимый вопрос не переписывается. Лишние слова прошлого хода уводят поиск.
- Якоря берутся из прошлого ответа, не из воображаемого списка документов.
- Поиск вызывает `search_agent` уже с этой строкой, не с сырым вопросом пользователя.
