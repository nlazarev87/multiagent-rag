# Координатор

Код: [src/coordinator.py](../src/coordinator.py).

Собирает один вопрос в ответ. Либо сразу список имён файлов, либо граф LangGraph.

## Вход и выход

`run(query, dialog_id)` возвращает `answer`, `status`, `document_names`, `sources`. Статусы: «подтверждён», «не подтверждён», «нет ответа».

Память диалога координатор читает через `dialog.get_dialog` и дописывает ход через `dialog.add_turn`. Сохранение на диск делает API.

## Граф

`select → clarify → search → answer → check`. Из `check` три выхода:

- снова `answer`, если отзыв не просит другие документы;
- снова `search`, если отзыв содержит «документ» или «Разных значений»;
- `finish`, если статус уже не «не подтверждён» или попытки кончились.

Потолок попыток — `attempts` в `config/runtime.json` (сейчас 2).

## Инварианты

- Каталог срабатывает по шаблонам `config/routing.json`, до модели. Совпадение идёт по словам имени файла, не по куску внутри слова. Запросное слово может начинаться со слова имени («госты» подходит к «гост»). Пересечение нескольких таких отметок сужает список. Пустое пересечение возвращает все имена, а не пустой ответ.
- Шаблон «какие документы» в каталог не входит: так вопрос про содержание документа не превращается в список файлов.
- `finish` для вопроса «сколько» оставляет строку из обзора таблицы, если проверка ответ не подтвердила. Иначе неподтверждённый ответ заменяется на «В документах нет ответа.» и источники очищаются.
- Ссылка `[n]` без оставшегося источника снимается до записи хода. Группа `[1, 2]` разбирается на отдельные номера, повторный хвостовой номер убирается раньше, в ответе.
