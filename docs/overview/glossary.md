# Глоссарий

- **RAG (retrieval-augmented generation)** — генерация ответа с опорой на найденные в корпусе фрагменты.
- **Чанк** — фрагмент документа фиксированного размера с перекрытием; единица индексации и поиска.
- **Эмбеддинг** — векторное представление текста; близость считается косинусно.
- **Гибридный поиск** — объединение векторного и пословного каналов.
- **top-k** — сколько чанков поднимает поиск.
- **Faithfulness** — доля утверждений ответа, подтверждённых источниками.
- **Переписывание (rewrite)** — повторный поиск по переформулированному запросу после провала `check`.
- **`data/ui/workspace.json`** — файл состояния диалогов, оценок 1–5 и дерева папок.
- **`/ready`** — эндпоинт готовности API.
- **Агент** — шаг конвейера (`catalog`, `select`, `clarify`, `search`, `answer`, `check`), реализованный отдельным модулем.
