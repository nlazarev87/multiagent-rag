# Выбор прошлого хода

Код: `select_agent` в [src/agents.py](../src/agents.py). Вызывается до уточнения и поиска.

## Вход и выход

На вход — текущий вопрос и сохранённые ходы. На выход — пустой список или один прошлый ход. Этот ход ограничивает поиск, только если вопрос ссылается на предыдущий.

## Что нельзя сломать

- Пустая история ничего не выбирает. Новый вопрос не тащит за собой прошлые документы.
- Вопрос ссылается на предыдущий, если в нём местоимение из `_PRONOUNS` или нет своих слов. Тогда берётся последний ход.
- Обычный вопрос цепляется к старому ходу, только если совпал код или хотя бы два содержательных слова. Одного общего слова мало.
- В поиск имена документов прошлого хода попадают только для такого зависимого вопроса. «Она» ищет в тех же файлах. Новый вопрос ищет по всему индексу.
