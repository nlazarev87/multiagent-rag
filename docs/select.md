# Выбор истории

Код: `select_agent` в [src/agents.py](../src/agents.py). Вызывает координатор до уточнения и поиска.

## Вход и выход

На вход — текущий вопрос и сохранённые ходы. На выход — пустой список или один прошлый ход. Этот ход потом ограничивает поиск, только если вопрос зависимый.

## Инварианты

- Пустая история даёт пустой выбор. Новый вопрос не тащит за собой прошлые документы.
- Зависимый вопрос — местоимение из набора `_PRONOUNS` или вопрос без своих слов. Тогда берётся последний ход.
- Независимый вопрос цепляется к старому ходу, только если совпал код или хотя бы два содержательных слова. Одного общего слова мало.
- В поиск имена документов прошлого хода попадают лишь для зависимого вопроса. Уточнение «она» ищет в тех же файлах. Новый вопрос ищет по всему индексу.
