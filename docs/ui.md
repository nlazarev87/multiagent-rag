# Страница

Код: [src/web/index.html](../src/web/index.html). Один файл, без сборки. Светлая схема, шрифт Segoe UI.

Три колонки: диалоги, середина с вкладками «Агент» и «Документы», справа вкладки открытых документов. Внизу логин и роль. Без сессии видна форма входа или создания администратора.

## Поведение

- `loadUi` ходит в `GET /ui`. Ошибка не создаёт диалог и не затирает уже нарисованное. Повтор через 2 секунды.
- Пока человек пишет дерево, пришедший ответ не подменяет его. Иначе сервер затирает папку, которую только что перетащили.
- Правый щелчок по полосе под списком и по шапке режима «Документы» открывает меню корня, пункт «Новая папка». Меню файла — удаление.
- Папку нельзя бросить в саму себя и внутрь того, что уже лежит в ней. Бросок в папку выше по дереву разрешён.
- Когда `/ready` впервые отвечает 200, список запрашивается ещё раз. До этого старт может отдать дерево без свежего индекса.
- Текст вставляется через `textContent` и `createElement`. `innerHTML` и `insertAdjacentHTML` в файле быть не должно: это проверяет `tests/test_api.py`.

Файлы на диске остаются плоским inbox. Папки существуют только в `workspace.json`.

## Проверка

`tests/test_api.py` смотрит маршруты и запрет `innerHTML`. `tests/test_tree_drop.py` проверяет, что папку нельзя положить внутрь себя. Отдельной проверки качества ответа у страницы нет.
