# Страница

Код: [src/web/index.html](../src/web/index.html). Один файл, без сборки. Светлая схема, шрифт Segoe UI.

Три колонки: диалоги, середина с вкладками «Агент» и «Документы», справа вкладки открытых документов. Внизу полоса цвета `--chrome`: слева логин, справа имя роли. Значения приходят из `GET /me`. Выход и свой пароль — с этой полосы, в том числе когда открыто управление: полоса лежит поверх него. Без сессии видна форма входа. Если людей ещё нет — кнопка «Создать администратора», второй раз эта форма не показывается.

## Поведение

- `loadUi` ходит в `GET /ui`. Ошибка не создаёт диалог и не затирает уже нарисованное. Повтор через 2 секунды. Ответ 401 открывает форму входа: полоса логина скрыта, управление закрыто, повтор не крутится.
- Пока человек пишет дерево или ещё тянет папку, пришедший ответ не подменяет его. Иначе сервер затирает папку, которую только что перетащили.
- Если загружать некуда и базу создать нельзя, кнопка загрузки скрыта. Иначе страница спрашивает базу до записи. В списке только базы, куда вход уже есть и включено «загружать». «Новая база» есть у того, у кого общее создание баз или у роли/лично включено «загружать»: имя задаёт он, вход только у него.
- Клик по источнику открывает `/kb/{id}/documents/{name}/preview`. Если id нет, имя ищется в `GET /documents`. Одно совпадение открывается. Два совпадения сами не открываются: на экране оба имени баз. Текст одного имени не берётся из кэша другой базы. Вкладка снова открывает ту базу, с которой её открыли.
- «Управление» видно при любом общем действии. «Люди», «Роли», «Группы», «Доступы» и «Журнал» — только при своём действии. Журнал не запрашивается по таймеру: каждое открытие дописало бы событие. Обновление — кнопкой «Обновить», она не подставляет событие клика вместо id строки. Продолжение списка — «Дальше» по времени последней строки и её id.
- Загрузка файла идёт отдельным запросом, не через общий `fetch`. Ответ 401 на ней тоже открывает форму входа.
- Роль в группе на экране поясняется так: это все, у кого роль есть сейчас и будет потом. Действие роли само базу не открывает. «Открыть себе» не меняет матрицу роли. На экране «Доступы» люди и роли видны по имени. «Открыть» человека показывает ему базу: если действий на ней не было, включается «спрашивать». Экран не перерисовывается, строка остаётся на месте. Поиск сверху фильтрует базу или человека.
- Правый щелчок по полосе под списком и по шапке режима «Документы» открывает меню корня, пункт «Новая папка». Меню файла — удаление.
- Папку нельзя бросить в саму себя и внутрь того, что уже лежит в ней. Бросок в папку выше по дереву разрешён.
- Когда `/ready` впервые отвечает 200, список запрашивается ещё раз. До этого старт может отдать дерево без свежего индекса.
- Текст вставляется через `textContent` и `createElement`. `innerHTML` и `insertAdjacentHTML` в файле быть не должно: это проверяет `tests/test_api.py`.

Файлы на диске остаются плоским inbox. Папки базы лежат в её `tree.json` рядом с папкой файлов. Пока тест подменяет только `workspace.PATH`, дерево остаётся в этом файле.

## Адаптивность

Главный shell без горизонтального скролла `body` (`overflow-x: hidden`). Колонки резиновые: `--left`/`--mid` заданы через `clamp()`, документ — `minmax(0, 1fr)`. Саши пишут инлайн-ширину, но `bindSash` клампится к ширине окна (`window.innerWidth`).

Брейкпоинты в `@media`:

- `1280` и `1080` — сужение `clamp()` колонок, чтобы документу оставалось место.
- `900` — две панели: диалоги сворачиваются в дровер (`#dialog-toggle`, `body.drawer`, скрим). Админка `#admin` переходит в одну колонку, навигация становится верхней горизонтальной лентой (`overflow-x: auto`), кнопка «Назад» прижата справа (`position: sticky`).
- `720` — одна панель с табами «Чат»/«Документ» (`#mtab-chat`/`#mtab-doc`, `body.mobile-doc`). Таблица пользователей складывается в стек (карточки, шапка скрыта).
- `560` — уменьшенные отступы шапки, тулбара и превью.

Таблицы и матрица: `.table-card` скроллится по горизонтали (`overflow-x: auto`), а не обрезается. Матрица прав баз `.kb-matrix` лежит в обёртке `.kb-scroll` (`overflow-x: auto`), первая колонка прилипает (`position: sticky; left: 0`). Строки аудита переносятся (`flex-wrap`), тип события — чип; длинные имена ролей/баз/логинов — ellipsis.

Доступность: `focus-visible` на кнопках/вкладках/инпутах/селектах/summary; на touch (`pointer: coarse`) цели не меньше 28px; у сашей расширенная зона попадания (`sash::before` 18px); пустые состояния центрируются (`#log`/`.canvas` с `.empty`). Тёмная тема задана токенами `body[data-theme="dark"]` и действует на всех брейкпоинтах.

## Проверка

`tests/test_api.py` смотрит маршруты и запрет `innerHTML`. `tests/test_ui_responsive.py` — grep-проверки адаптивности (`@media`, таблицы в прокручиваемом контейнере, отсутствие фиксированного `min-width` окна, дровер/лента). `tests/test_tree_drop.py` проверяет, что папку нельзя положить внутрь себя. Отдельной проверки качества ответа у страницы нет.
