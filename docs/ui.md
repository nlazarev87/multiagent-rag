# Интерфейс

Код: [src/web/index.html](../src/web/index.html). Один файл, без сборки. Стили — светлая схема Cursor, шрифт Segoe UI.

Три колонки: диалоги, середина с вкладками «Агент» и «Документы», справа вкладки открытых документов.

## Поведение

- `loadUi` ходит в `GET /ui`. Ошибка не создаёт диалог и не затирает уже нарисованное. Повтор через 2 секунды.
- Пока `treeWriting` или `treePending`, пришедшее дерево не подменяет локальное. Иначе ответ сервера затирает папку, которую пользователь только что перетащил.
- Правый щелчок по полосе под списком и по шапке режима «Документы» открывает меню корня, пункт «Новая папка». Меню файла — удаление.
- Папку нельзя бросить в саму себя и внутрь своего потомка. Бросок в предка разрешён.
- Когда `/ready` впервые отвечает 200, список запрашивается ещё раз. До этого старт может отдать дерево без свежего индекса.
- Текст вставляется через `textContent` и `createElement`. `innerHTML` и `insertAdjacentHTML` в файле быть не должно: это проверяет `tests/test_api.py`.

Файлы на диске остаются плоским inbox. Папки существуют только в `workspace.json`.

## Проверка

`tests/test_api.py` смотрит маршруты и запрет `innerHTML`. `tests/test_tree_drop.py` проверяет, что сценарий перетаскивания не вкладывает папку в себя. Отдельного узла scorecard нет.
